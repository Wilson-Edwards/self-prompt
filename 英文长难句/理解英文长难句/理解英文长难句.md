# 英文长难句：怎么练才能"尽快理解"并"真正掌握"

> 承接 `../英文断句助手/英文断句助手.md`（断句助手提示词）。
> 核心结论：**断句助手当日常支架，语法树当偶尔的诊断工具，真正的能力来自"自己先切 + 回译 + 结构清单"。** 三者不是三选一，是分工，比例大概是 60 / 10 / 30。

## 1. 先分清两个目标，不然会一直原地踏步

很多人练长难句练了几个月没长进，是因为把下面两件事当成了一件事。

| | 理解（decode） | 掌握（automatize） |
| --- | --- | --- |
| 要解决的问题 | 这一句到底在说什么 | 下次没工具、没时间，我也能一遍读懂 |
| 靠什么 | 外部解析：翻译、断句、语法树 | 自己的反复提取练习（做错、纠正、再遇到） |
| 时间尺度 | 10 秒到 1 分钟 | 几周，且同一结构要遇到 6~10 次 |
| 断句助手 / 语法树能不能替代 | 能，而且很有效 | **不能**，看过答案 ≠ 会做 |

一个类比：断句助手是计算器，语法树是说明书，而"掌握"是心算。做题时该用计算器，但真实阅读时没人给你递计算器。

**所以"哪种工具更好"这个问法本身有偏差。** 正确问法是：*日常读东西卡住时用什么、事后纠错用什么、练能力用什么*。

## 2. 三种方案的分工与代价

| 方案 | 解决什么 | 优点 | 主要代价 | 建议用法 |
| --- | --- | --- | --- | --- |
| 断句助手（断句 + 逐段释义 + 骨架） | 单句理解 | 快，几乎零成本；顺带积累语块和句型 | 直接给答案 → 容易"假懂"；不训练自己切分 | 日常主力，但改成"我先切、你判卷" |
| 语法树 | 解释"为什么这么理解" | 修饰关系显式化，能纠正自己的误判 | 慢；越难的句子越容易画错；不告诉你阅读顺序 | 同一类结构反复错时，用一次定位病因 |
| 自己先切 + 回译（+ 结构清单） | 掌握 | 唯一能自动化、能迁移的方法 | 慢、费脑子，需要每天坚持 | 每天 5~10 句，作为真正的训练 |

一个更直接的说法：

- **只断句助手**：理解速度很快提升，独立解读能力几乎不涨。因为你每次都在看别人的答案，而且是正确率 100% 的答案。
- **只语法树**：容易变成"学语法"而不是"练阅读"。看懂树 ≠ 能读懂，因为人读的是线性文字，不是树。
- **只自己硬扛**：能涨，但慢，且错误会固化（自己理解错了没人纠）。
- **三者组合**：理解不卡、错误被纠、能力在涨。

## 3. 为什么语法树不适合当主力

语法树有它的价值，但它有五个硬伤，正好卡在"尽快"和"掌握"这两个诉求上。

**3.1 树不提供阅读顺序，而卡住的原因恰恰是顺序**

长难句难在"读到一半忘了前面"（工作记忆被打满），不在"看不出谁修饰谁"。树把句子重新组织成二维层级，你读完树就懂了，但**下次遇到同样的句子你还是从左到右读，还是会在同一个位置卡住**。树解决了病症的一种，而你的病是另一种。

**3.2 最难的句子，树最难画，也最容易画错**

树最不可靠的地方，正好是长难句最高发的地方：

- 并列与省略：`and` 后面省掉了哪些词，树上常常"消失"了，而这里恰恰是理解的关键。
- 后置修饰的宿主：`which` 修饰前面的名词、还是整个句子？`that` 是定语从句还是同位语/宾语从句？树画成一种，另一种可能就没了。
- 比较结构与 `than` 后省略。
- 否定范围：`not ... because` 是"因为不"还是"不是因为"。
- 分隔结构（主语和谓语之间插了一长串）。

风险在于：**AI 能给你一棵语法上自洽、但语义上错的树**，而你没有第二个参照系，就会把它当真理接受。越是你看不懂的句子，你越没能力验证那棵树 —— 这是"高置信度的错误"，比不给解析更糟。

**3.3 信息密度过高，读树的成本接近重新学一遍**

一句 40 词的句子，树的深度经常到 5~6 层，标注还要带缩写。读它要几十秒到几分钟，一天读 20 句就崩了。而且这些标注（NP / VP / RelCL / FinCL）本身不是你的阅读能力，考试和工作中也不会用到。

**3.4 树倾向于"过度分析"**

人理解一句话不需要把所有成分都标完。树给你一种"必须分析完整"的错觉，于是你把时间花在分析上，而不是"读懂 + 记住这个句型"。分析是手段，很多人把它当成了目的。

**3.5 结论：什么时候才用树**

只在三种情况用，用完就停：

1. 你在同一类结构上连续错了 3 次以上（比如总是搞不清 `that` 的三种身份）→ 用树集中定位一次病因，然后回到结构清单去记"信号 + 处理动作"。
2. 你已经有了自己的解读，想验证一个具体判断："这个 `which` 是不是修饰整句？" → 直接问单点问题，不要它画全树。
3. 一篇文章里有一句是全篇理解的关键，其他都读懂了 → 用树把它彻底搞透。

真正的日常替代品是**缩进骨架**（§10 有示例）：用缩进表示层级，比树好读十倍，信息几乎不损失。

## 4. 断句助手：适合当日常支架，但要改用法

断句助手（现在这份提示词）产品质量不错，它做对了一件关键的事：**按"能独立成义"的意群切**，这正好对应母语者真实的阅读单位。它的五块输出（断句 / 逐段 / 整句 / 结构 / 难点）覆盖了"看懂"需要的全部信息，而且成本几乎为零。

**它的问题不在输出质量，在用法。**

默认用法是"我贴句子，它给全套答案"。这会带来三个副作用：

1. **假懂**：你看到"尽管新政策上周已经公布"这段中文，会觉得"我懂了"，其实你懂的是译文，不是英文。
2. **跳过最关键的挣扎**：真正产生能力的动作是"自己切的时候犹豫、切错、被指出错在哪"，这叫合意困难（desirable difficulty）。看答案把这个环节删掉了。
3. **不产生错点记录**：没有错点，就没有针对性的练习对象，于是永远在"遇到 → 看懂 → 忘掉"的循环里。

**改法：把断句助手从"答案机"改成"教练"。**

| 用法 | 你做什么 | 它做什么 |
| --- | --- | --- |
| 判卷模式（推荐默认） | 先自己切分 + 写主干 + 猜意思 | 只标出切错的位置和译错的地方，**不给正确答案** |
| 追问模式 | 拿不准某个切点 | 只回答"为什么这里不能切"，不重述整句 |
| 回译批改 | 合上原文，写一句中文（或口头说） | 逐点比对，指出漏译、多译、译反的地方 |
| 变式训练 | 懂了一句 | 给出同一结构的 5 个不同内容的句子 |
| 拆句训练 | 懂了一句 | 把长句改写成 2~3 个简单句，验证你是不是真懂成分关系 |

具体提示词在 §11，可直接复制。

**一个尺度**：断句助手最好用在"你已经在挣扎，卡住了 30 秒以上"的时候。一遇长句就贴给 AI，等于把阅读这件事外包出去，读得越顺，能力越差。

## 5. 真正更有效的四件事

这四件事合起来才是"掌握"的路径。它们不依赖任何工具，AI 只负责纠错和出题。

### 5.1 主干先行：先问三个问题

读任何长句，第一个动作不是翻译，是**找骨架**。三个问题，按顺序：

1. 这句的**谓语动词**是哪个？（一个简单句只有一个谓语，看见第二个谓语就一定有连接词、从句或省略）
2. 主语的**中心词**是哪个？（不是紧挨谓语的那个词，而是最靠左的核心名词）
3. 谓语后面是**宾语**还是**表语**？（决定后面整串东西是"做什么"还是"是什么"）

实操技巧：**先删三类东西，剩下的就是主干**。

- 介词短语（`in / on / with / by / of ...` 到下一个边界）
- 逗号、破折号、括号夹住的部分
- 引导词开头的从句（`that / which / who / because / although ...`，整段划掉）

删完你会发现主干通常只有 5~8 个词：`Researchers have failed to persuade the companies.` 主干出来，句子的态度、语气、方向就定了，剩下的都是补充信息，读不懂也不至于全盘崩塌。

**这是性价比最高的一个动作**，也是断句助手输出里"结构 → 主干"那一行最值得看的地方。

### 5.2 意群朗读：把结构变成节奏

结构识别靠的是**对停顿位置的自动反应**，这个反应只能靠嘴和耳朵建，靠眼睛看不出来。

规则只有三条：

1. **只在语法边界呼吸**，读错就重来（读不动、必须乱喘气的地方，就是你语法结构没吃透的地方）。
2. 每句读 **3 遍**：慢速（清楚的意群边界）→ 正常速度 → 稍微快一点（感受"意群整块往外蹦"）。
3. **读出声**，不要默读。默读不改节奏，朗读才会把语块写进肌肉记忆。

**唯一的判断标准**：读的时候有没有出现"啊原来是这样"的断裂感。顺畅 = 懂了；需要在某个位置反复回读 = 那个位置就是你的结构漏洞，单独拎出来看。

对长难句尤其有效的原因：一旦你能一口气读完一句 40 词的句子而不卡，说明你已经在用"块"而不是"词"处理它了，这时候理解的瓶颈已经从结构转移到词汇。

### 5.3 结构清单：8 类，每类只记"信号 + 停顿 + 处理"

长难句不是无限种，中文母语者 90% 的卡点集中在这 8 类。**不要学语法体系，学"看到什么 → 做什么"的配对动作。**

| # | 结构 | 一眼认出的信号 | 断在哪 / 怎么读 | 中文处理 | 常犯的错 |
| --- | --- | --- | --- | --- | --- |
| 1 | 后置定语（介词 / 分词 / 不定式） | 名词后紧跟 `of / in / with`、`doing / done`、`to do` | 修饰语前断，与名词合读 | 前置成"……的"，太长就切成短句 | 把后置定语误当谓语中心 |
| 2 | 定语从句 | `which / who / whom / whose / where / when` | 引导词前断 | 非限制性用"这/它"另起一句；限制性前置 | `which` 修饰紧邻名词还是整个主句 |
| 3 | 同位语 / 同位语从句 | 逗号或破折号、`that`、`namely / i.e.` | 两侧都断，当插入读 | 译成"即/也就是" | 把同位语 `that` 当成定语从句 |
| 4 | 插入语 | 两个逗号/破折号/括号夹住；去掉后句子仍完整 | 整体跳过，读完再回填 | 括起来放句首或句末 | 把插入语当主干，导致主干断裂 |
| 5 | 状语从句 / 状语短语 | `because / although / if / when / while / so that`、`according to / instead of` | 引导词前断 | 中文习惯前置；让步用"尽管…但…" | 漏掉让步、条件的逻辑方向 |
| 6 | 并列与省略 | `and / but / or` 后突然出现 `that / which / do / to / will` 等 | 并列连词前断 | 把后半句缺的成分补回来再译 | `and` 后面省了什么，完全没意识到 |
| 7 | 名词性从句 / it 形式主语 | `that / what / whether / how` 出现在谓语后或句首；`it is ... that` | 引导词前断 | 从句整块当一个名词用 | 把 `it` 当作代词去前文找指代 |
| 8 | 特殊语序与比较 | 否定词/`only` 句首、`than` 后省略、`not ... because`、`rather than` | `than / because / only` 前后断 | 先定否定范围，再译比较对象 | `not ... because` 译反；`than` 后补错对象 |

**用法**：不要一次背完。每次被指出一个错误，就去表里找到对应那一行，在"常犯的错"里加一条自己的案例。这张表长到 15 行左右时，你就基本不缺结构知识了，缺的只是速度。

**最关键的一行是 #6 和 #8**。这两类在语法书上篇幅最小，但在真实长句里杀伤力最大，而且语法树最帮不上忙。

### 5.4 回译与变式：唯一的"真懂"检验

读懂的标准不是"看中文觉得通顺"，而是能**再造出来**。三级台阶：

| 级别 | 做什么 | 通过标准 |
| --- | --- | --- |
| L1 回译 | 合上原文，用自己的中文说一遍 | 不漏让步/条件/否定，不把因果说反 |
| L2 复述 | 合上原文，用**英文**口述这句的意思（可以变简单） | 说得出主干，说得出每个修饰在修饰谁 |
| L3 变式 | 故意改一个成分，判断意思变不变 | 能准确说出"改这个会变意思，改那个不会" |

L3 才是分水岭。比如把定语从句里的时态改一下、把 `although` 换成 `because`、把 `not` 的位置挪一下 —— 如果你能预判意思怎么变，说明你不是在背译文，而是在操作结构。

这一级最适合让 AI 出题（§11 提示词 2 和 3）。

## 6. 单句训练 SOP（20 分钟，5 步）

这是每天的核心动作。材料来自你本来就要读的东西（技术文档、论文、新闻），不要用题库 —— 脱离上下文的孤立句子，练出来的能力也停在孤立状态。

| 步 | 时间 | 动作 | 产出 |
| --- | --- | --- | --- |
| 1 限时硬读 | 2 分钟 | 不查词、不用工具，从头读到尾，卡住也不许回读，用一句话记下"我以为它在说什么" | 直觉摘要 + 卡点位置 |
| 2 划骨架 | 3 分钟 | 圈出所有谓语动词 → 划掉介词短语 / 插入部分 / 从句 → 写出主干 | 一行主干 |
| 3 自己切 | 3 分钟 | 用 `/` 切意群，写一句中文 | 自己的切分 + 译文 |
| 4 对答案 | 2 分钟 | 交给断句助手，**用判卷模式**（只判错不给答案），自己先改 | 错点 |
| 5 加固 | 10 分钟 | 出声朗读 3 遍 → 合上原文回译 L1 → 挑 1 处做 L3 变式 → 把错点写进清单 | 错点清单一行 |

关键约束：

- **第 4 步必须你先写**。先看答案的练习等于没练。
- **第 5 步的朗读不能省**。§5.2 说过，结构自动化靠节奏建立。
- 一天 5 句为佳。时间不够就压到每句 8 分钟：保留第 2、3、5 步，第 1、4 步各压 1 分钟。

**错点清单**（全流程唯一需要长期保存的东西，一页纸就够）：

```text
日期     句子片段                          错的原因                      归类
11-20    are quietly reshaping the skills  把宾语从句的谓语当成主句谓语   #7 名词性从句
11-20    the skills those workers need     没看出省略了 that/which        #6 并列与省略
```

"归类"这一列就是通向 §5.3 的索引。**同一类出现 3 次就去单独练它**（这也是 §3.5 第 1 条说的"该画树的时机"）。不归类、只记"这句没看懂"，等于没有错点。

## 7. 一周怎么排（不要每天做同样的事）

| 时间 | 内容 | 目的 |
| --- | --- | --- |
| 每天 | 5 句真实材料走一遍 SOP | 保持曝光 + 收集错点 |
| 每天 | 出声朗读昨天那 5 句（3 分钟） | 把结构变成节奏，形成复现 |
| 隔天 | 从错点清单挑 1 句做 L2 复述 / L3 变式 | 从"理解"推向"掌握" |
| 每周一次 | 统计清单，找出出现 ≥3 次的那一类，让 AI 出 5 个同结构变式句集中做 | 把单点漏洞补成结构能力 |
| 每周一次 | 30 分钟泛读（不分析，只用 §5.1 找主干，读完就过） | 量是自动化的前提 |

两个容易忽视的点：

1. **泛读和精读必须都有**。只精读没有量，自动化不起来；只泛读没有纠错，错误会固化。
2. **材料难度控制在 i+1**。一句话里有 3 个以上生词时，练结构是无效的，你练的是猜词。先扫词，再决定要不要做结构训练。

## 8. 什么时候该用哪个（决策表）

| 场景 | 用什么 | 时间预算 |
| --- | --- | --- |
| 正在读文档/邮件，某句卡住 | 断句助手，省流模式（只要断句 + 一句意思） | 30 秒 |
| 想确认自己切得对不对 | 断句助手，判卷模式 | 1 分钟 |
| 同一类结构连续错 3 次以上 | 语法树 / 缩进骨架，集中定位一次 | 5 分钟，用完就停 |
| 只有一个具体疑问（这个 which 修饰谁） | 直接问单点问题，不让它画全树 | 30 秒 |
| 想真正记住这个句型 | 变式句（同结构 5 句）+ 出声朗读 | 10 分钟 |
| 想检验自己是不是真懂 | 合上原文回译 / 英文复述 | 2 分钟 |
| 想提升整体阅读速度 | 限时泛读 + 意群朗读，**不用任何解析工具** | 30 分钟 |
| 要练"现场能读懂"的能力 | 只做主干训练 + 朗读，禁用工具 | 每天 10 分钟 |

最后一行值得单独说：**要练现场能力，就必须有"没有工具"的时段。** 全程有 AI 陪同的阅读，本质是"AI 读给你听"，你的能力和 AI 是否可用绑在一起。

## 9. 常见误区（大部分人可以少走半年弯路）

1. **把"看译文觉得很顺"当成进步**。顺畅感来自中文，不来自英文。真正的进步信号是：两周后遇到同结构句子，你不需要工具。
2. **迷信语法树**。树是诊断报告，不是阅读能力。把树当日常工具，等于每次读句子前先做一次语法分析。
3. **一遇长句立刻贴给 AI**。这条最隐蔽：它让你的阅读体验变好，同时让你的能力停止增长。
4. **只默读不朗读**。默读维持你现有的断句习惯，朗读才会重建它。
5. **生词没清就开始分析结构**。3 个以上生词时，结构分析只是在给猜词找理由。
6. **追求每句都彻底分析**。投入产出比会崩，正确做法是"只对反复出错的那类认真分析"。
7. **记语法笔记，不记错点清单**。语法笔记是抄别人的体系，错点清单才是你的问题。
8. **泛读和精读只做一个**。见 §7 第 1 点。
9. **两周换一个方法**。任何方法都要 4 周才看得出效果，频繁换方法等于没练。

## 10. 一个长句的完整示范：四种处理方式看同一句

原句（真实语料级别，三重省略关系词 + 主语谓语被 24 个词隔开）：

> Researchers who have spent years arguing that the tools most workers now rely on are quietly reshaping the skills those workers need have largely failed to persuade the companies that fund them.

### 10.1 断句助手方式（先自己切，再判卷）

自己切的版本（示意，故意留错）：

> Researchers / who have spent years arguing that the tools / most workers now rely on / are quietly reshaping the skills / those workers need have largely failed / to persuade the companies that fund them.

被判卷指出的问题：

- `Researchers / who...` 切错：`Researchers` 不能独立成义（违反断句助手里"能单独成义"的判据，和 `the number of students /` 属于同一类错误）。
- `arguing that the tools / most workers now rely on` 切错：把先行词和它的定语从句切开。
- `the skills / those workers need have largely failed` 切错：`those workers need` 是修饰 `skills` 的省略式定语从句，`have largely failed` 是主句谓语，两者中间必须断，且不能把 `skills` 和它的定语从句分开。

正确切法：

> Researchers who have spent years arguing / that the tools most workers now rely on / are quietly reshaping the skills those workers need / have largely failed to persuade the companies / that fund them.

从这里能看出断句助手的真正价值：**它的每个切点都对应一个"这里必须换气"的位置**，而你的错误切点，全部落在"读起来顺口但语法上不该停"的地方 —— 这就是要练的直觉。

### 10.2 主干方式（§5.1，最有价值的一步）

删掉三样东西：`who...` 定语从句、`that...` 宾语从句、`that fund them`，剩下的：

> **Researchers have largely failed to persuade the companies.**
> 研究者大体上没能说服这些公司。

主干一出来，句子 80% 的意思就定了：**是一句"研究者的失败"**，后面所有从句都只是在说"哪些研究者""什么工具""什么技能"。这句话读不懂的关键从来不是词汇，是你没先把这条主干拔出来。

### 10.3 树的方式（以及为什么不适合当主力）

结构树（功能标注式）：

```text
S
├─ NP 主语
│   ├─ N: Researchers
│   └─ RelCL: who have spent years arguing
│       └─ ObjCL: that [the tools [RelCL: most workers now rely on]]
│                 are quietly reshaping [the skills [RelCL: those workers need]]
└─ VP 谓语
    ├─ V: have largely failed
    └─ to persuade the companies [RelCL: that fund them]
```

问题一眼可见：

- `are quietly reshaping` 视觉上挂在 ObjCL 的 VP 下，和主句的 `have largely failed` 只差两级缩进 —— **最难的地方（谁才是主句谓语）在图上反而是最不醒目的**。
- 三个 `[RelCL: ...]` 里有两个是**省略了关系词**的（`the tools most workers now rely on`、`the skills those workers need`），图上必须靠你自己补标注才看得出来；不知道要补标注的人，看树也看不懂。
- 读这棵树要在 5 层缩进之间来回跳，30 秒起步，而它教不会你"读到这里要停下来等一个从句结束"。

### 10.4 缩进骨架方式（推荐替代品）

```text
Researchers                                    ← 主语中心词
├ who have spent years arguing                ← 定语从句（修饰 Researchers）
│  └ that the tools ...                       ← 宾语从句（arguing 的宾语）
│     ├ 主语：the tools [most workers now rely on]     ← 省略 which（修饰 the tools）
│     └ 谓语：are quietly reshaping the skills
│              └ [those workers need]        ← 省略 which（修饰 the skills）
└ have largely failed to persuade the companies   ← 主句谓语（与主语隔了 24 个词）
   └ that fund them                            ← 定语从句（修饰 the companies）
```

同样信息，一目了然，而且**它的阅读顺序就是句子顺序**。日常想看清结构，用这个，不用树。

### 10.5 加固（§5.4）

- **朗读**：按 10.1 的四个切点（五段），慢速两遍、正常一遍。第 3 个切点（`...those workers need / have largely failed...`）最需要练，因为这里是全句唯一真正反直觉的位置。
- **L1 回译**：合上原文说 —— "多年来一直论证'大多数人现在用的工具正在悄悄改变这些人所需的技能'的研究者，基本上没能说服资助他们的公司。"
- **L3 变式**（自己能判断才算懂）：
  - `have largely failed` 改成 `has largely failed` → 错，主语中心词是 Researchers，不是 skills。
  - `those workers need` 改成 `those workers will need` → 意思基本不变。
  - `that fund them` 改成 `funding them` → 变成分词修饰，语法可通但语气更"附带说明"，且会削弱"资助者"这个身份限定。
  - `arguing` 改成 `argue` → 语法崩，`who have spent... argue` 没有连接词。
- **错点清单**：归类为 `#6 并列与省略`（两处省略关系词）+ `#2 定语从句`（隔位修饰），共 2 条。

## 11. 可直接复制的三个提示词

配套 `../英文断句助手/英文断句助手.md` 使用。共同点：**先要我输出，再让它判卷**，不许它一上来给答案。

### 11.1 判卷模式（日常主力）

```text
你是英文长句判卷员。我会给你：一句英文、我自己用 / 做的切分、我写的主干、我的中文译文。
请只判卷，不要重写正确答案：
1. 逐个切点判断「对 / 勉强 / 错」，错的用不超过 15 个字说明为什么。不要给出正确的切分。
2. 主干：对或错；错的话指出是主语中心词、谓语、还是宾语判错了。
3. 译文：逐条指出漏译、多译、译反、情态或让步信息丢失，指到具体片段。
4. 最后只输出一行：这次我最该改的一个动作。
不要复述整句译文，不要输出语法讲义，不要列语法术语清单。
如果我连续两轮都没改对，才给出正确切分和解析，并说明我卡住的原因。
```

### 11.2 回译批改（检验真懂）

```text
我会给一句英文，以及我不看原文写下的中文回译（可能写得比较口语、也有错）。
请逐片段比对，只指出下面这几类问题：漏译、多译、把让步/条件/因果/否定/情态译丢或译反。
每条按「原文片段 → 我的译法 → 问题」的格式给，最多 5 条，按严重程度排序。
最后给一个 0~3 分的准确度评分（3 = 信息无损，2 = 细节有偏差，1 = 主干对细节错，0 = 理解偏了）。
不要重写我的整段译文，最多给我改其中一处作为示范。
```

### 11.3 变式与拆句（把理解变成掌握）

```text
基于这句英文的结构，出一组小练习（共 5 题），先只出题、不给答案，等我答完再逐题批改：
1. 同结构变式（2 题）：保持从句类型和结构骨架不变，换掉全部内容和词汇（避免用原句的词），我给中文意思，你核对。
2. 改动判断（2 题）：把原句改动一处（换连词 / 换时态 / 挪否定词 / 删掉关系词 / 改成分词），问我意思变不变、为什么。
3. 拆句（1 题）：把原句改写成 2~3 个简单句，不许丢信息，我来做，你判卷。
批改时只讲我做错的地方，不要顺带讲整句语法。
```

## 12. 如果只记一条：最小可行方案

**每天 5 句真实材料 → 先自己切和划主干 → 让 AI 只判卷 → 错点归到 8 类里 → 每周把出现 ≥3 次的那类用变式句打一遍。**

- 断句助手：60% 的用处在这里（判卷 + 卡住时救急）。
- 语法树：10% 的用处，只在"同一类错 3 次"时用一次，而且优先用缩进骨架代替。
- 自己切 + 朗读 + 回译：这才是 30% 里最关键的部分，也是唯一会写进长期能力里的部分。
- **每天必须有一段"没有工具"的时间。** 这是"掌握"和"看得懂"的分界线。

判断这套方法有没有用的标准，不是"今天读得顺不顺"，而是两个可测的指标：

1. 同一类结构，两周后还要不要工具？（要 → 继续，方法没错，量不够）
2. 40 词的句子，第一遍读完后能不能说出主干？（不能 → 回到 §5.1 单练主干，其他都先放）

> 说明：本文的方法主张基于阅读与学习研究的一般结论（语块加工、合意困难、提取练习优于重复阅读），不是精确的实验配方；个体差异很大，建议按上面两个指标自己校准，而不是照抄时间表。
